# Working on this site

This is a designer's portfolio built with plain Astro (no React). The owner reads this code to learn from it.

## Readable code is the top rule

- Use full, descriptive names. `caseStudy`, not `entry`, `d` or `cs`. `selectedCategory`, not `active`.
- One idea per line. No clever one-liners, chained ternaries or compressed functions.
- Prefer an `if` statement with named booleans (`const isHomePage = ...`) over inline conditions.
- Add comments that explain why something is there, in plain English.
- Write CSS with one property per line and class names that say what the thing is (`filter-pill-knob`, not `knob`).
- When a name is a judgment call, ask the owner before settling on it.
